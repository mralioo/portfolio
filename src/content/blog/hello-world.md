## How to write the next one

Drop a new markdown file into `src/content/blog/`, e.g.:

```md
---
title: "My Post Title"
description: "One sentence for the blog index and SEO."
date: 2026-11-03
tags: ["ai", "philosophy"]
draft: false
---

Your content here, in plain Markdown.
```

Set `draft: true` to keep working on a post without it showing up on the
public `/blog` index.
